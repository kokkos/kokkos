# Kokkos Core Documentation

The Kokkos Core documentation is hosted at <https://kokkos.org/kokkos-core-wiki/>
and tracks the `develop` branch.

Its source is maintained in the
[kokkos-core-wiki](https://github.com/kokkos/kokkos-core-wiki) repository. To
report a problem with the documentation or to contribute to it, please open an
issue or a pull request there.

## Where to start

- [Get started](https://kokkos.org/kokkos-core-wiki/get-started.html):
  installing Kokkos (package managers or from source) and configuring your
  project
- [Programming guide](https://kokkos.org/kokkos-core-wiki/programmingguide.html):
  the programming model and its main building blocks
- [API references](https://kokkos.org/kokkos-core-wiki/api-references.html):
  Core, Algorithms, Containers, and SIMD APIs

## In this directory
