# kokkos-skill

Skill to help agents work with Kokkos.
- Write correct, portable and idiomatic code
- Review or identify issues in existing code

## Installation

Just copy this directory (``kokkos``) under the appropriate directory for your harness. These paths can be relative to either your home directory or project directory from which you'll launch the harness.
- Claude Code: ``.claude/skills``
- Opencode: ``.agents/skills``
- Codex: ``.codex/skills``
